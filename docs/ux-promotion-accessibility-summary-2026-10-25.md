# 第三十批：促销列表完整辅助标签

基于第二十九批已验证主线 `9d9e6f4`。该批[原生日志](https://github.com/maxduke/card-pilot/actions/runs/40184470984)中的 `UI Spend` 列表按钮具有合并标签，但未包含实际显示的奖励。源码为整个列表项设置 `accessibilityElement(children: .ignore)`，因此子视图的奖励和归档标记不会补入该自定义标签；标签构造也确实缺少这两项。这里验证的是原生辅助功能树中的信息，不把它等同于实际 VoiceOver 操作。

本批在已有合并标签中补充非空奖励与已归档状态，放在活动标题／状态之后，再沿用主办方、期数、日期、报名及进度。没有奖励时不产生空奖励提示，未归档时不宣告已归档。视觉布局、业务含义、归档保存和导航沿用既有实现，不增加展示框架或状态。

新增一项原生 UI 回归，沿用既有概览夹具和操作能力：检查无奖励项的标签，检查有奖励且未归档的标签，真实编辑归档并保存，再展开归档历史验证完整标签和入口，重启后读回并再次进入详情。保留三个界面检查点，原生点击日志提供实际合并标签；原有 86 项 UI 不删改，完整回归成为 223 项单元／集成加 87 项 UI，共 310 项。定向预检先核对原生标签及真实归档流程，再走完整 PR／main 工作流。

本地 Swift 语法、旧用例保留与数量及 diff 检查通过，原生预检、正式 310 项回归与合并主线验证仍待执行。真实设备与 VoiceOver 的逐项朗读、焦点及手势仍需实际操作验收。
