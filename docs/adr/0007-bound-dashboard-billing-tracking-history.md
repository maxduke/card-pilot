# 以追踪起始账期限制 Dashboard 账期历史

状态：已接受

## 背景

Dashboard 需要保留账户加入 CardPilot 后尚未标记还清的普通旧账期，但不能因为每次打开都从任意历史月份生成账期而无限增长。只有明确保存为账期记录的更早账期需要作为历史事实继续显示。

## 决策

`CreditCardAccount` 持久化 `trackingStartCycleKey`，表示账户开始追踪的名义账单月份。新账户默认加入当月；若按录入的规则计算，更早账期的还款日仍在今天或以后，则选择其中最早一期。回溯范围由固定日或账单日后天数规则限定，不自动补入任意逾期历史。预览明确显示所选账期及日期，是否已经还款由用户确认。首版不提供起点编辑入口，也不改变已有账户的追踪起点。Dashboard 对每个账户生成从该账期至当前账期后两个月的账期键，并合并保存的未还账期；已还账期仍按既有状态过滤。无效起始账期由模型校验拒绝，未来起始账期不生成反向历史。

## 后果

追踪起点之前未保存的普通旧账期不会出现在 Dashboard；加入前名义月份中仍未到还款日的账期不再被漏掉。需要追溯更早事项时，用户可明确创建账期记录，后续版本再考虑可编辑的追踪起始账期。数据结构明确保留了将来扩展的边界，不把无限历史计算责任交给 Dashboard。
