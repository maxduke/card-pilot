# 以追踪起始账期限制 Dashboard 账期历史

状态：已接受

## 背景

Dashboard 需要保留账户加入 CardPilot 后尚未标记还清的普通旧账期，但不能因为每次打开都从任意历史月份生成账期而无限增长。只有明确保存为账期记录的更早账期需要作为历史事实继续显示。

## 决策

`CreditCardAccount` 持久化 `trackingStartCycleKey`，表示账户加入 CardPilot 的名义账单月份，默认是加入当月。首版不提供编辑入口。Dashboard 对每个账户生成从该账期至当前账期后两个月的账期键，并合并保存的未还账期；已还账期仍按既有状态过滤。无效起始账期由模型校验拒绝，未来起始账期不生成反向历史。

## 后果

账户加入前未保存的普通旧账期不会出现在首版 Dashboard；需要追溯时，用户可明确创建账期记录，后续版本再考虑可编辑的追踪起始账期。数据结构明确保留了将来扩展的边界，不把无限历史计算责任交给 Dashboard。
