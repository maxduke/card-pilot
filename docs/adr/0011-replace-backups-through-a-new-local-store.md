# 通过独立本地存储恢复完整备份

完整备份采用带独立格式版本的 JSON，保留稳定 UUID、十进制金额字符串、自然日键及全部历史关系；设备提醒、常用时区、应用锁和最近使用偏好不纳入备份。恢复采用整库替换，不合并现有对象；文件内重复 ID、复合键冲突、缺失引用、未知版本或违反领域约束的数据整份拒绝，避免把冲突误解为更新。

用户预览数量并明确确认后，先保存可再次导入的恢复前备份，再在独立新存储中写入并核对完整往返，最后原子切换存储选择文件；切换前的任何失败都保留原有活动存储，旧存储及历史恢复前备份不自动清理。启动失败提供重试与备份恢复入口且仍遵守应用锁，禁止自动清库或回退到空库；原存储无法读取时明确无法生成逻辑备份，保留原文件并允许用户确认后从有效备份恢复。
