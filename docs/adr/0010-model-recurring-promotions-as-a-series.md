# 以促销系列组织循环活动

创建系列时只有首期保留本次输入的报名状态和报名日期；后续需要报名的各期从“尚未报名”开始，报名日期为空，不需要报名的规则保持不变。复制到下个月也不复制报名事实。修改“本期及以后”的共同条款时，保留其他各期独立的报名状态、报名日期和归档状态；这些事实只能在对应期明确修改。报名截止日仍可作为共同条款按月份顺延。

首版将按月重复的活动建为一个促销系列，不提前支持周、季度或自定义频率。系列中的每个有效期仍是独立促销，各自拥有进度、报名状态和适用卡；各期起止日始终由首期整体顺延月份计算，可表达自然月或 15 日至次月 14 日等周期。创建时一次生成结束日期前容得下的所有完整期；后续修改可只影响本期或本期及以后，不截短末期或改写历史期，以免跨期混合封顶、退款和已确认的交易分配。
