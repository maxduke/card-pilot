# 通知与账期操作闭环

本批连接已有本地提醒与账期详情，不改变持久化 Schema、账务规则版本或交易归属规则。

## 行为

- 在应用启动时安装并持有 `UNUserNotificationCenterDelegate`。普通通知点击沿用已发送通知的 `accountID + cycleKey` 载荷，直接定位账户和名义账期；覆盖日期跨月也不改变目标身份。
- 通知目标暂存于应用级路由器，冷启动可先接收、后解析。仅在场景 active、应用已解锁、备份操作结束且所有 sheet 关闭后呈现。认证失败保留目标；连续点击多个通知以最后一个目标为准。
- 各层 sheet 共用呈现登记：从准备呈现到系统完成关闭一直占位，嵌套选择器关闭不会释放父编辑页；视图销毁会清理登记。等待期间不切换 tab、不关闭表单、不重建已有导航。完成或取消原编辑并关闭已有 sheet 后，再打开账期详情。
- 在当前存储中重新解析目标；账户已删除、恢复后 UUID 不存在、追踪前无保存记录、关闭后的无效账期或规则无效时，显示无法打开的说明，不跳到另一个账期。已还账期仍可打开并撤销。
- 首页、卡片详情和账户详情均可进入同一账期详情，就地标记已还、撤销、调整本期日期、查看所属账户。还款状态立即保存，并显示反馈；共享账户的卡片使用同一份账期状态。
- 日期编辑保留取消确认和锁屏期间输入。日期覆盖与还款完成时间分别更新；撤销已还款保留覆盖，清空所有事实才删除稀疏记录。调整账单日后按规则重新推算未单独覆盖的还款日，保存前验证日期顺序和关闭日期。
- 保存前查询复合唯一性并校验账户规则，失败回滚，成功触发提醒重建。计划仍采用最多 48 条账务提醒的时间窗口；已还款取消还款提醒，撤销重新加入，覆盖日期更新原标识的时间。
- 设置页的“发送测试提醒”申请必要权限并安排 5 秒后的通用通知。使用独立固定标识，重复点击替换同一条测试请求，账务重建不会移除它，不占用 48 条账务窗口。测试消息不含账户信息，也不提供账期定位；真实账务提醒用于验证深链。

## 自动验证

新增 `NotificationBillingTests` 覆盖有效和无效载荷、冷启动等待、后台返回、认证失败与重试、嵌套呈现和恢复等待、最后目标优先、精确账户与已还历史定位、目标不存在与账户关闭、还款撤销及唯一性、日期覆盖与规则不变、无效日期回滚，以及“保存 → 重新调度 → 目标和触发日期”集成流程。

`NotificationSchedulerTests` 补充测试提醒权限拒绝、首次申请、请求失败、固定槽位与重建保留。已有通知窗口、交错重建和失败保留测试继续运行。

Linux 本地检查：Swift 6.1 对全部应用与 XCTest 源码的语法解析通过；隔离副本的 61 项 XCTest 通过。隔离副本使用通知 API 替身和普通模型类，仅验证纯计算和调度逻辑，不验证 SwiftUI、UIKit、SwiftData 或真实系统认证。原生构建及完整测试结果以本批 PR 的 iOS CI 为准。

## 真机验收（待执行）

准备两个不同账户、一个共享账户，各保留未还和已还账期；将真实账务提醒时刻设为常用时区几分钟后，提前量选当天。深链验收使用真实账务提醒，设置页通用测试消息只验证送达。

1. **冷启动**：退出应用后点击真实账务通知，核对银行、卡片身份、名义账期与日期。开启应用锁后重复，认证前任何页面、sheet、辅助功能均不可访问。
2. **后台与失败**：后台点击通知，取消设备认证，确认仍锁定；再次认证成功后打开原目标。无锁时回到前台直接打开。前台收到提醒显示系统横幅，点击也打开相同目标。
3. **编辑保留**：在交易第二步、卡片编辑、账户编辑、活动编辑及其中的选择器分别输入未保存内容，切后台再点通知。解锁后仍是原编辑页，字段与步骤保留；关闭子选择器仍不跳转，最终完成/取消并关闭现有 sheet 后才打开账期。普通解锁不产生跳转。
4. **多次点击**：保留编辑期间分别点两个账户的通知，最后完成编辑后打开最后一个目标；关闭该详情不会重复打开旧通知。
5. **目标失效**：已送达提醒对应账户删除、恢复为不含该账户的备份后再点通知，出现明确说明；关闭账户前的有效账期仍能打开。已还款的旧通知打开已还状态，可撤销。
6. **账期操作**：从首页、卡片和账户分别打开详情；标记已还、撤销、重进页面核对。共享卡状态一致，未保存的日期编辑取消不影响记录。日期跨月后名义账期不变；非法顺序不能保存；撤销已还保留覆盖。
7. **提醒重排**：检查完成后还款请求取消、撤销恢复、改日期后触发时间变化，账单提醒保持应有状态；多次快速调整后最终计划与最后保存值一致。
8. **测试提醒**：允许/拒绝/首次授权分别尝试；连续发送只保留一条。发送后手动刷新账务计划仍可收到测试通知。测试消息前台与后台均检查，专注模式、静音与系统通知设置可能影响声音和横幅。
9. **视觉与辅助功能**：浅色、深色、最大辅助字号、VoiceOver 检查账期身份、操作名称、日期和保存失败说明。

系统认证、真实通知点击、呈现动画及视觉验收未以 Linux 测试代替。进程被终止后的编辑草稿恢复仍属于后续批次。
