# UX 第十三批：备份导出记录 · 2026-10-11

基于第十二批及其滚动回归修正后的已验证主线 `a9461d5`，接续 O17 的日常导出反馈。本批已集成实现，尚未完成原生验证。

## 行为

- 默认文件名包含生成此次备份的设备本地日期和时间，例如 `CardPilot-备份-2026-10-11_18-30-05.json`。系统文件面板仍允许修改名称；完整备份内容、校验及后台生成路径保持原有实现。
- 备份页面显示“上次成功导出”。只有系统文件导出回调返回成功，才保存完成时间；生成 JSON、显示文件面板、取消和失败均不更新记录。
- 导出记录属于本机偏好，重启后继续显示，恢复备份不会覆盖。没有记录时显示“尚无成功导出记录”；无效的偏好时间按无记录处理。
- 文案明确这是本机的导出记录，提示妥善保管文件。它不能证明文件仍在目标位置、已传到其他设备或目前可以恢复。现有恢复预览、替换确认、完整校验及恢复前副本保留。

没有新增 Schema、备份字段、存储服务、云端能力、依赖或清理操作。

## 验证

新增一项原生 UI 回归，使用现有独立测试账本：读取导出记录，打开真实系统导出面板检查默认文件名，取消后核对记录未改变、没有错误提示，再重启到最大辅助字号检查记录、按钮点击区域和文字裁切。之后以只读的启动偏好设置固定日期，单独检查较长的已有导出时间布局；它不用于验证保存成功或时间持久化。保留“备份成功导出记录”“系统备份导出文件名”“最大字号取消导出后记录”“最大字号已有导出记录”四张原生截图。

此回归不把打开面板或取消当作导出成功，也不模拟系统保存回调。实际保存到本机／文件提供者、成功时间跨重启读回、文件访问和恢复需按 O21 真机验收；代码中的成功回调写入可静态确认，模拟器取消检查不能替代实际保存验收。

本地 Swift 6 语法解析与 diff 检查仅是补充。保留前序全部 38 项 UI 用例与最终滚动助手、60 分钟完整原生作业；预计完整 GitHub iOS workflow 运行 216 项单元／集成测试和 39 项 UI 测试，最终 HEAD 全部通过及截图确认后合并，再验证 main。尚未运行的检查不记为通过。
