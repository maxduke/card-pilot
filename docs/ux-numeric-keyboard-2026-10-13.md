# UX 第十五批：交易金额键盘退出 · 2026-10-13

基于第十四批已验证主线 `b6bdaf7`，处理 O13 中交易表单的数字键盘退出路径。当前实现及新增用例仍待完整原生 CI、当前 HEAD 截图检查和合并后的 main 验证；不据本地语法解析判断键盘呈现或布局已经通过。

## 行为

交易金额和促销计入金额聚焦时，在系统键盘工具栏右侧提供“收起键盘”按钮，点击区域至少 44 点。点击结束输入，保留金额原文、地区小数格式和手动分配，不触发提交或关闭编辑页。普通商户等文字字段不显示这个仅管理数字字段的按钮。

使用编辑页内部的可选焦点枚举，区分交易金额和各活动 UUID 对应的计入金额。新建表单自动聚焦、固定提交、手动选择活动、卡片选择和原消费选择沿用原来的焦点操作；滚动收起键盘、固定提交区、取消保护和草稿保存继续使用现有路径。收起动作仅清除焦点，不改金额、字段绑定、草稿快照或业务保存。

## 验证

新增两个独立的原生 UI 用例，使用现有 core 夹具，原有 42 项用例和通用助手保持不变：

- 普通字号输入 `125.50`，真实点击工具栏按钮，确认键盘消失、原文保留和表单继续打开；编辑商户时不显示失效的数字字段按钮。将计入金额改为 `100.25`，再次收起并核对原文；终止和重启后继续草稿，确认手动分配保留，再实际保存、重启读回 `125.5 CNY` 交易及 `100.25 CNY` 计入金额，交易只创建一次。
- 最大辅助字号从第一次启动生效，分别操作交易金额和计入金额工具栏，检查完整无障碍标题、可点击性、44 点点击区域及屏幕内边界。收起后核对原值和编辑页仍在，固定提交及返回修改操作可到达，并检查二者没有重叠。

每次都先确认软件键盘和按钮存在，再直接点击一次按钮，不在此前调用可能滚动收起键盘的助手。当前 HEAD 需要检查以下五张新增截图，并检查普通和最大字号的既有原消费选择列表截图，验证新增焦点管理与选择页衔接：
