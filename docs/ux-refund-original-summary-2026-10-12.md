# UX 第十四批：退款原消费摘要 · 2026-10-12

基于第十三批已验证主线 `d3886aa`，跟进第九批原生截图中选中原消费内容被省略的问题。实现已集成，完整原生验证尚未完成。这是 O13 的一项可读性跟进；其余错误定位、键盘体验及 O21 真机验收仍逐项推进。

## 行为

退款表单使用“选择原消费（可选）／更改原消费”原生按钮，点击后收起金额键盘并打开“选择原消费”列表页。列表保留原有 UUID 候选和不关联选项，当前选择显示勾选及无障碍选中状态；每行完整日期、商户和金额可随 Dynamic Type 换行，点击区域至少 44 点。选择后关闭列表并直接更新原有选中 UUID，取消或下滑关闭不修改关联。入口按钮的无障碍值提供完整选中信息。下方显示可换行的完整日期、商户、原消费金额／币种及有效／已冲正状态。使用现有日期与精确 Decimal 格式，空商户沿用“未填写商户”。原消费已冲正的独立退款说明继续单独显示。

摘要只从当前卡片可关联的消费及当前选中 UUID 读取；切换选择立即显示对应消费，选择不关联或换卡清除后不显示。金额是原消费金额；输入退款金额不会改写它，也不将其解释为剩余可退余额。退款币种、草稿优先级、分配建议、超额确认和保存路径沿用现有行为。

只新增选择页的临时呈现状态，没有新增业务数据状态、Schema、草稿／备份字段、格式化服务或依赖。
