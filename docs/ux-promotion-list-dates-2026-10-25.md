# 第二十八批：促销列表完整有效期

基于第二十七批已验证主线 `26a693d`。第二十六批[原生基线运行](https://github.com/maxduke/card-pilot/actions/runs/40056599504)的真实促销列表截图中，主办方与完整日期范围放在同一行，两者都被省略，日期显示为 `2026年10月01日-20…`，无法从列表读出结束日期。这是 O18 已记录的信息层级问题，第二十七批单卡历史修改没有涉及该页面。

本批将有效期独立为一行，并沿用已有日期格式、次要文字样式及列表间距，允许日期按可用宽度换行。主办方仍保持简短的一行概览，完整内容仍在详情与既有无障碍标签中。活动标题、奖励、报名与进度、系列选择、排序、编辑和导航均保持原样；不引入新组件、状态或数据格式。

沿用已有促销概览 UI 流程，增加普通／最大辅助字号的列表原图检查点，随后仍执行五种进度、截止日期可见性、真实详情入口及最大字号进度的全部原有断言。不为文字排版增加镜像实现的单元测试，用例数量仍为 223 项单元／集成加 86 项 UI，共 309 项。

先做原生定向预检，检查普通与最大字号的日期完整性、首屏信息和详情入口；在可用的最小支持屏幕模拟器上补充同一流程。具体机型、系统、截图和真实结果将在取得后记录，不能从当前 iPhone 16 Pro 的结果推定小屏已通过。正式 PR 的完整 CI 与当前绿色运行原图验收通过后，按既定授权合并并验证主线。
