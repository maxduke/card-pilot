# CardPilot 0.1.12

## 更新内容

- 保存活动前完整展示累计达标门槛、计入上限、单笔门槛和优惠笔数条件；金额条件互相矛盾时给出提醒，继续允许按银行条款保存和手动修正。
- 从活动选择已有交易时区分推荐交易与其他交易，增加金额币种说明、收起键盘和就地错误反馈。
- 修复重新编辑活动分配时，已保存的手动计入金额被原交易金额替换的问题。
- 系列活动的删除确认明确具体期次和有效期；详情可直接归档或恢复本期，保留其他期及已有进度。
- 修复系列上一期／下一期按钮在同一列表行中响应异常的问题。

沿用现有本地数据和备份格式，已有交易、人工分配及各期独立报名状态保留。

## 下载与安装

[GitHub Release](https://github.com/maxduke/card-pilot/releases/tag/v0.1.12) 提供
`CardPilot-unsigned.ipa` 和 `CardPilot-unsigned.ipa.sha256`。
IPA 未签名，需要自行签名安装，最低支持 iOS 17。
也可通过 [CardPilot 软件源](https://maxduke.github.io/card-pilot/) 获取新版。
