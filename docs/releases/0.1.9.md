# CardPilot 0.1.9

## 更新内容

- 增加报名截止本地通知：有明确截止日期且尚未报名的活动，默认提前 1 天及当天提醒，可在“通知与提醒”调整节点或关闭，沿用现有提醒时刻和固定时区。
- 标记已报名、归档或删除活动后取消对应提醒；点击通知可打开具体活动，保留应用锁和编辑期间的导航保护。
- 交易金额统一放在独立区域右对齐，避免随商户或卡片名称长短改变位置；保留完整精度、币种、退款符号和冲正样式，并扩大整行点击范围。
- 促销列表显示报名截止日期，报名截止后明确提示；详情的报名与资格区前移，并提供报名提醒设置入口。
- 所有活动归档后，明确说明数据仍在归档中并提供查看入口。

本版不更改数据库 Schema 或备份格式。账单、还款和报名共用最近 48 条提醒的计划窗口，打开应用时补充后续计划；已过的提醒时刻不补发。最大辅助字号下，长金额保留全部数字并允许换行。

## 下载与安装

[GitHub Release](https://github.com/maxduke/card-pilot/releases/tag/v0.1.9) 提供
`CardPilot-unsigned.ipa` 和 `CardPilot-unsigned.ipa.sha256`。
IPA 未签名，需要自行签名安装，最低支持 iOS 17。

## 验证范围

回归范围包含 245 项单元／集成测试、102 项 UI 测试，以及 5 项 SE 3 小屏深色及增强对比度检查。
功能提交 `f889eba` 已通过全部门禁；版本更新后的 PR、合并主线及标签包仍按各自提交验证，最终结果以对应 [GitHub Actions](https://github.com/maxduke/card-pilot/actions) 和发布页记录为准。

标签构建须核对版本 `0.1.9`、build `1`、Bundle ID `com.maxduke.CardPilot`、IPA 结构和 SHA-256。
模拟器和构建验证不替代 iPhone 实际通知送达、系统专注模式及点击通知的真机验收。
