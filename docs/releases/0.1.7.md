# CardPilot 0.1.7

## 更新内容

- 午夜和后台跨日返回时，自动更新首页待办、待还／逾期状态、卡片与账户详情及促销期限。
- 常用时区或系统时间变化后重新计算“今天”并重建提醒，覆盖跨月跨年、夏令时和时钟回拨；设备旅行时区变化不改写常用时区设置。
- 日期刷新保持现有导航、所选账期／促销期和编辑输入，不修改已保存的自然日期。
- 改进核心 UI 自动化的滚动辅助函数，支持找回屏幕上方的操作按钮。

## 下载与安装

[GitHub Release](https://github.com/maxduke/card-pilot/releases/tag/v0.1.7) 提供 `CardPilot-unsigned.ipa` 和 `CardPilot-unsigned.ipa.sha256`。此包未签名，需要自行签名安装，最低 iOS 17。升级前建议从设置页导出完整 JSON 备份。

本版不更改数据库 Schema。版本更新后的 PR CI、主线 CI、标签构建及附件校验均属于发布流程；以对应 GitHub Actions 和发布页记录为准。

1. 升级后打开已有账本，检查卡片、账期、交易与促销均保留。

5. 用真实账务提醒核对送达、点击到账期详情与跨日后状态。设置页测试通知仅验证送达，不验证账期定位。
