# CardPilot 0.1.11

## 更新内容

- 优化交易列表的金额排版：空间不足时币种另起一行，数值保持整段，避免小数末位被拆行。极长金额支持横向查看，保留已保存值的全部数位和辅助字号。
- 确认促销时显示剩余优惠笔数；未预选时就地说明报名、币种、门槛、上限、叠加冲突或手动取消状态，保留人工核对和修正。
- 同名月度活动显示期次、有效日期和状态，便于分辨本期、往期、未开始及已归档活动，继续支持历史补录。
- 确认页可直接展开活动规则与排除项，查阅后保留已选活动和人工计入金额。
- 编辑卡片时补足数字键盘上方的滚动余量，避免工具栏遮住末四位输入框底部。

## 下载与安装

[GitHub Release](https://github.com/maxduke/card-pilot/releases/tag/v0.1.11) 提供
`CardPilot-unsigned.ipa` 和 `CardPilot-unsigned.ipa.sha256`。
IPA 未签名，需要自行签名安装，最低支持 iOS 17。

## 验证范围

回归范围为 248 项单元／集成、109 项 UI，以及 8 项 SE 3 小屏深色／增强对比度检查。最终结果以各提交的 [GitHub Actions](https://github.com/maxduke/card-pilot/actions) 和发布页记录为准，原生测试通过后检查对应实际截图。

标签构建须核对版本 `0.1.11`、build `1`、Bundle ID `com.maxduke.CardPilot`、IPA 结构和 SHA-256。模拟器与构建验证不替代 iPhone 使用验收；此前偶发模拟器导航卡顿的根因仍未确认。

本次保留已保存金额的展示精度，沿用原有金额存储格式；过多有效位在持久化时的规范化行为见[验证记录](https://github.com/maxduke/card-pilot/blob/v0.1.11/docs/ux-transaction-confirmation-2026-11-08.md)。
