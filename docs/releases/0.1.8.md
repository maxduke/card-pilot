# CardPilot 0.1.8

## 更新内容

- 编辑账户时，切换账期前提示处理尚未保存的日期修改，避免误丢输入。
- 搜索促销系列时展示并打开匹配的期次，同时保留整个系列的历史导航。
- 交易促销搜索分别展示已选活动和其他匹配结果，保留已选活动的计入金额。
- 首页账户摘要更紧凑，完整账户身份保留在无障碍信息中。
- 改进小屏、深色模式、最大字号和数字键盘下的录入与账期阅读体验。
- 修复早期 V3 账本中零金额促销计入的备份导出与恢复兼容问题；新建和编辑仍要求正金额。
- 减少多余的全量交易查询与重复计算，按已有职责整理卡片、交易和促销编辑代码。

## 下载与安装

[GitHub Release](https://github.com/maxduke/card-pilot/releases/tag/v0.1.8) 提供
`CardPilot-unsigned.ipa` 和 `CardPilot-unsigned.ipa.sha256`。
IPA 未签名，需要自行签名安装，最低支持 iOS 17。升级前可从设置页导出完整备份。

## 验证范围

回归范围包含 236 项单元／集成测试、99 项 UI 测试，以及 2 项 SE 3 小屏深色模式测试。
发布提交须通过 PR 和合并主线的现有门禁；标签构建核对版本号、Bundle ID、IPA 结构和 SHA-256。
最终结果以对应的 [GitHub Actions](https://github.com/maxduke/card-pilot/actions) 及发布页记录为准。

模拟器与构建验证不替代真机通知送达、系统认证、文件选择器及实际 VoiceOver 验收。
