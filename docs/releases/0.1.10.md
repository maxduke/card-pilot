# CardPilot 0.1.10

## 更新内容

- 修复设置了优惠笔数上限的逐笔活动不参与自动预选的问题。已报名或无需报名、同币种、金额达到单笔门槛且优惠笔数还有剩余时，逐笔活动现在会正常预选。
- 多个符合条件的活动均允许叠加时同时预选。例如消费 24，同时满足任意金额活动与单笔满 20 的逐笔活动，两个活动均会勾选并各计入 24。
- 最后一个可用优惠仍可预选，笔数用完后不再预选；手动取消活动后继续修改金额，会保留取消状态。确认页说明同步更新，商户、渠道等附加条款仍需用户核对。

## 下载与安装

[GitHub Release](https://github.com/maxduke/card-pilot/releases/tag/v0.1.10) 提供
`CardPilot-unsigned.ipa` 和 `CardPilot-unsigned.ipa.sha256`。
IPA 未签名，需要自行签名安装，最低支持 iOS 17。

回归范围包含 246 项单元／集成测试、104 项 UI 测试，以及 5 项 SE 3 小屏深色及增强对比度检查。

标签构建须核对版本 `0.1.10`、build `1`、Bundle ID `com.maxduke.CardPilot`、IPA 结构和 SHA-256。
原生回归已覆盖两个活动的预选、保存后重启读回，以及金额跨门槛和手动取消；模拟器与构建验证不替代 iPhone 实际使用验收。
