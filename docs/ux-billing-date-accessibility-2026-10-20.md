## 实现

账户关闭日期、实际账单日、实际还款日和单期日期编辑共用小型 `BillingDatePicker`。辅助字号时将标题独立成行，日期沿用系统 `DatePicker`，使用年／月／日滚轮。普通字号继续使用原有默认日期样式。直接绑定原来的日期状态，不另存一份选择，也不改变时区、日历、日期校验、共享还款事实或保存／回滚。

`MonthKeyPicker` 在辅助字号下以完整换行的标题与月份作为导航入口。原生 List 中的选项保留完整年月、已选标记及选择语义，打开时滚动至已选项；选择后更新原绑定并返回。沿用原来的当前月相对范围和额外保留已选月份的逻辑，没有改成任意范围的日历或增加新的持久化状态。普通字号仍使用原菜单。

同一账务区域的 `BillingDayPicker` 在辅助字号下同样将标题独立成行，使用系统导航选择列表，避免“每月 N 日”与标题争用宽度。它同时用于新卡向导和账户编辑；1–31 日／1–90 天的选项及绑定保持原样。普通字号保留菜单。没有限制系统字号或缩小文字来隐藏裁切。

使用的系统 API 见 Apple 的 [WheelDatePickerStyle](https://developer.apple.com/documentation/swiftui/wheeldatepickerstyle)、[NavigationLinkPickerStyle](https://developer.apple.com/documentation/swiftui/navigationlinkpickerstyle) 和 [DynamicTypeSize](https://developer.apple.com/documentation/swiftui/dynamictypesize)。这些文档说明样式与字号机制，不能替代本项目的实际布局验收。
