## 指标与边界

每个用例收集原生 Clock、应用内存和命名区间指标：

- `DraftSave` 包围草稿校验、JSON 编码、大小校验及原子受保护写入。
- `TransactionCommit` 包围 `TransactionEditActions.save`，包含该函数的校验、关系变更、持久化及失败回滚。

区间只在显式定义 `PERFORMANCE_TESTING` 的模拟器构建中编译，普通 Debug 和发行构建不包含新增观测逻辑。使用 Apple 的 [OSSignposter](https://developer.apple.com/documentation/os/recording-performance-data) 与 [XCTOSSignpostMetric](https://developer.apple.com/documentation/xctest/xctossignpostmetric/init(subsystem:category:name:))；配对 ID 区分每次调用，`defer` 保留抛错路径的结束事件。

Clock 包含原生 UI 自动化和就绪／值断言；应用区间不覆盖全部 SwiftUI 更新。保留 Xcode 原始单位、聚合结果和十个样本，不从 Clock 减去区间值来推断剩余渲染时间。模拟器结果也不能证明真机流畅度；如后续需要生产性能修复，仍须按实际问题补充应用栈或 Instruments 归因及可比较的修复前后证据。
