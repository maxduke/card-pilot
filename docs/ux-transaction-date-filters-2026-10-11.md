# UX 第十批：交易日期与币种筛选 · 2026-10-11

基于第九批已验证主线 `10741e9`，处理产品评估 O15：在已有交易筛选上增加日期和币种，并显示结果笔数。

## 行为

- 日期范围支持全部、本月、上月与自定义；本月／上月由常用时区的当前自然日解析，跨日和时区更新会重新计算。自定义保存自然日期，包含起止两天，按交易日期筛选，入账日期不改变归属。
- 自定义默认当月第一天至今天；调整开始日期时保持起止顺序，结束日期不能早于开始日期。选择过的自定义范围保留，避免切换预设后重复填写。
- 币种选项来自账本的实际交易币种，保留当前已选币种，即使之后该币种不再有记录。与卡片、类型、状态、促销和搜索共同筛选。
- 列表和无匹配结果显示实际笔数；未指定状态时，原有默认口径仍包含已冲正交易。按日期范围和币种提供可移除标签，筛选页清除和列表清除全部一起重置新条件。

本批不增加金额统计或汇率换算，不改 Schema、账务事实、草稿或备份格式。现有交易行、详情、退款和保存入口继续使用。

## 验证

- 单元测试检查闰年、年初上月、月份两端、自定义跨年及单日范围，确认按交易日期而不是入账日期匹配，并验证币种与原有条件的组合。
- 独立模拟器场景包含本月、上月、更早和未来月份，混合消费／退款、CNY／HKD与已冲正记录；在闰日、年初、月末进行完整备份往返和筛选检查。
- UI 回归检查结果笔数、默认包含已冲正、有效状态、无匹配结果、清除、自定义日期控件，以及最大字号移除日期／币种条件、44 点点击范围与原生点击区域审计。
