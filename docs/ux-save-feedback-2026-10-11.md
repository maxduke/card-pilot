# UX 第四批：交易保存反馈 · 2026-10-11

对应 [产品评估](product-ux-review-2026-10-10.md) 的 O04 中保存结果的可感知性，基于第三批已验证主线 `2b69748`。使用现有保存事件、SwiftUI 提示和弹层登记，不增加数据字段、依赖或状态管理框架。

## 行为

- 原有提示从保存事件触发起显示 3 秒，可能在编辑弹层关闭前已消耗显示时间；现在等待该次保存时的弹层登记释放后显示，再开始普通模式的 8 秒计时。嵌套交易详情中的编辑也采用同一规则。
- 提示保留准确金额、交易／退款类型和活动计入数量，整块可点关闭；增加可见叉号，按钮内容至少 44 pt 高，合并为一个辅助功能元素。
- 手动关闭会同时清理主界面与已呈现交易详情的提示，避免关闭详情后旧提示再次出现；收起提示不会撤销已保存交易。
- 使用系统 VoiceOver 环境状态，开启时取消自动收起；关闭 VoiceOver 后重新给予 8 秒。仅根页面发布一次保存结果播报，详情提示不重复发布。播报使用 Apple 的 [排队语音属性](https://developer.apple.com/documentation/foundation/nsattributedstring/key/accessibilityspeechqueueannouncement)，排在已有语音之后。
- 减少动态效果开启时，提示出现和关闭不使用位移动画或显式过渡动画；其他模式保留原有动画与一次成功触感。
- 应用失活时清理可见与待显示提示，各呈现层消失时清理本层提示。新确认使用新的计时版本；旧计时任务不能清除新确认或仍在等待弹层关闭的新保存结果。
- 将保存提示及文案从交易大文件移入共享文件，建卡、首页和其他业务流程保持现状。

## 验证

- 原有保存文案测试继续覆盖准确金额、退款、更新与活动数量。
- 两条新增 UI 回归验证整块提示关闭、嵌套编辑后的金额更新与重启读回、关闭详情后无重复提示、普通自动收起、后台返回无旧提示，以及最大辅助字号下的提示尺寸增长和关闭。
- 保留普通、嵌套编辑及最大字号提示的原生截图；截图和行为测试用于本批验收，不声称自动审计已覆盖全部短暂提示。
- 已通过四个修改 Swift 文件的本地 Swift 6 语法解析及 diff 检查。Linux 语法检查不验证 SwiftUI 类型、UIKit、原生呈现或语音。
- PR 当前提交和合并后的 main 均需运行完整 iOS workflow；当前原生结果尚待验证。

## 真机验收边界

开启 VoiceOver 后创建／编辑消费与退款，确认返回后保存结果只播报一次、不会打断正在阅读的内容，提示可找到并关闭；提示显示期间切换 VoiceOver，确认计时跟随状态变化。检查减少动态效果、最大辅助字号、浅／深色及最小支持屏幕。连续快速保存、嵌套编辑、关闭提示和切后台后检查没有旧内容覆盖新确认。

模拟器行为与截图不代表 VoiceOver 听觉、减少动态效果的系统设置联动、真机触感或真实通知送达已验收。本批不改变交易持久化、促销分配、草稿格式或本地提醒规则。
